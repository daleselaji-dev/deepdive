# DEEPDIVE ·《蓝井》

> 一次下潜 · 一宗悬案 · 一间红房间

浏览器可玩的**洞潜 / 深海洞穴调查**叙事恐怖游戏原型。第一人称洞潜体验：狭窄通道、低能见度、导引绳、氧气管理与方向迷失感。恐怖节奏取法《遗传厄运》与《穆赫兰道》——长时间的不安铺垫、环境音渐变、灯光异常，最后以超现实的「红房间」收束（《双峰》/《极乐迪斯科》式点睛）。

**全部资产程序化生成**：几何（噪声置换洞穴）、纹理（Canvas）、音频（WebAudio 合成）。零二进制素材、零版权风险。

## 快速开始

```bash
npm install
npm run dev      # 本地游玩：http://localhost:5173
npm run build    # 产物输出到 dist/
npm run preview  # 预览构建产物
```

要求 Node.js ≥ 18。建议佩戴耳机游玩，全程约 12–15 分钟。

## 游戏内容

你是一名私家侦探，受托调查失踪的洞穴潜水员 K。线索指向一处淡水天坑「蓝井」。跟随主线导引绳下潜，沿途发现前人遗留的线索（相机、写字板、割断的绳头……），直到你也看见 K 最后看见的东西。

**一条完整可到达的结局**：深入 → 环境异常（回声、灯光闪烁、导引灯熄灭）→ 有铺垫的惊吓 → 缺氧 → 深海生物的超现实显现 → 白光 → 红房间 → 致谢。结局由叙事推进自然触发，不需要任何隐藏操作。

## 画质档位

标题菜单与暂停菜单中可切换：

| 档位 | 内容 |
|---|---|
| **高** | 全分辨率、完整后处理（水下扰动/色差/颗粒/暗角/色分级）、体积光锥、高密度悬浮粒子 |
| **中** | 0.85× 渲染比例、精简粒子与后处理 |
| **低**（移动端默认） | 0.7× 渲染比例、最小粒子、关闭体积光锥与色差 |

## 技术架构

Vite + TypeScript + Three.js（WebGL2），无重型引擎，纯前端可静态部署。

```
src/
  main.ts               入口
  core/
    noise.ts            种子随机 + Simplex 噪声 / fbm（一切程序化生成的基础）
    quality.ts          画质档位定义与设备自动检测
    input.ts            统一输入层：键鼠(指针锁定) + 触控(虚拟摇杆)
    audio.ts            程序化 WebAudio 引擎：drone/呼吸/心跳/金属声/stinger/混响
  render/
    post.ts             单通道后处理：水下扰动、ACES、色分级、暗角、颗粒、闪光、淡入淡出
    particles.ts        悬浮物(灯锥调制)与气泡池
    volumetric.ts       加性体积光锥与辉光精灵
  game/
    game.ts             总编排：渲染循环、状态机(菜单/过场/游玩/暂停)、debug 钩子
    modes.ts            模式注册表（故事模式 + 模拟模式扩展点）
    story/
      cave.ts           程序化洞穴：Catmull-Rom 路径 + 噪声置换管壁、导引绳、线索、碰撞采样
      script.ts         叙事数据：节拍表(按进度 t 触发)、台词、介绍卡、致谢
      storyMode.ts      故事模式主逻辑：游动物理/氧气/节拍触发/惊吓/缺氧/结局迁移
      creature.ts       深海生物（惊吓近脸 + 巨大发光两种形态，自定义皮肤 shader）
      redroom.ts        红房间结局场景（波动幕布 shader、V 形纹地板、剪影人物）
  ui/
    hud.ts              氧气表/深度计/字幕/目标提示/介绍卡/致谢
    menu.ts             标题与暂停菜单
docs/
  DESIGN.md             设计文档：高概念、节拍表、技术架构、扩展点
scripts/
  capture.mjs           Playwright 截图自测（可选）
  e2e.mjs               Playwright 全流程端到端自测（可选）
```

### 核心机制

- **叙事按进度驱动**：玩家沿洞穴路径的归一化进度 `t ∈ [0,1]` 触发节拍表（雾色渐变、音效、灯光异常、目标更新、惊吓序列启动），保证每次惊吓前都有充分铺垫。
- **碰撞**：把玩家位置投影到路径采样点，按该处洞穴半径夹取——廉价且稳定，适配任意噪声置换的管壁。
- **渲染管线**：场景渲染到线性 HDR RenderTarget，再由单个合成 shader 完成扰动 → ACES 色调映射 → gamma → 显示空间色分级 → 暗角/颗粒/闪光/淡入淡出。
- **音频全程序化**：滤波噪声呼吸声、双振荡器 drone、程序脉冲响应卷积混响、惊吓 stinger（下滑锯齿 + 噪声爆发）等，均由 WebAudio 节点图实时合成。

## 「真实洞潜模拟模式」扩展点

架构已为第二模式预留（`src/game/modes.ts` 注册表 + `GameMode` 接口，标题菜单已有占位入口）。规划见 `docs/DESIGN.md`，要点：

- 复用：洞穴生成器（换参数/换种子）、游动物理、输入、渲染管线、音频引擎
- 新增：气体规划（三分之一法则、多瓶切换）、真实浮力/配重/微调、淤泥扬起致零能见度、沿绳摸黑折返、减压停留
- `StoryMode` 中叙事与机制已分层（`script.ts` 数据驱动），模拟模式只需实现 `GameMode` 接口并注册即可

## 自测脚本（可选）

```bash
npm i -D playwright && npx playwright install chromium
npm run build
node scripts/e2e.mjs        # 全流程：标题→探索→惊吓→缺氧→生物→红房间→致谢→返回菜单
node scripts/capture.mjs    # 关键节拍截图到 /tmp/dd-shots
```

游戏支持 `?debug=1` URL 参数，暴露 `window.__dd`（传送/触发事件/查询状态），供自动化测试使用。
