# 回声园 ECHO GARDEN — 洞穴潜水游戏原型（deepdive）

> 在一口以真实喀斯特天窗群为原型的水下洞穴里，你带着有限的气体、一卷导览线和一支头灯，独自下潜去收回一段"断掉的绳子"。
>
> 灵感来自《深海迷航》(Subnautica)、真实洞潜圈与「神秘园」类真实洞潜热点事件语境（游戏内容已全部虚构化处理）。当前阶段为**原型 + 工作流规划**，不是完整商业游戏。

---

## 快速开始（运行原型）

原型为纯 HTML/CSS/JS + Canvas 2D，**零依赖、零构建**。

**方式一：直接打开**

双击 `prototype/index.html`（或浏览器 `Ctrl+O` 打开该文件）。

**方式二：本地静态服务器（推荐，clipboard/localStorage 行为最完整）**

```bash
cd prototype
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

**操作**：`WASD / 方向键` 移动 · `鼠标` 控制头灯朝向 · `Shift` 缓速潜行（少扬尘） · `M` 声音开关 · `R` 重开

**目标**：下潜到最深处触碰「深处之物」，然后活着回到水面。注意氧气、导览线余量与扬尘（silt-out）。

**每日洞穴**：地图由日期种子生成，同一天全网玩家潜的是同一个洞；可用 `?seed=任意字符串` 自定义挑战地图。

## 原型已实现的核心张力

- **氧气**：持续消耗、运动加成消耗；备用气瓶 / 气室 / 水面三种补给。
- **导览线**：自动布线约 204 m，带回程箭头；线放完进入"无线区"。
- **能见度**：深度衰减黑暗 + 头灯光锥；贴墙/高速会扬起泥沙，局部能见度骤降。
- **未知深处**：深度与实体触发的叙事碎片、最深处的「深处之物」、触后回程光照异常。
- **社交钩子**：每日种子地图 + 一键复制下潜日志。
