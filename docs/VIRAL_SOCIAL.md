# DEEPDIVE · 传播与社交设计

> 传播不是发行阶段的事，是设计约束：**每个画面、每句字幕在写下时就要问——它值得被截图吗？**

---

## 1. "打开即震惊"的第一印象设计

首屏 = 免费广告位。规则：

1. **3 秒规则**：页面打开 3 秒内必须完成——全幅动态洞穴画面（相机缓漂）+ 巨型品牌字 + 一句钩子文案。无加载条恐惧：程序化资产保证秒开。
2. **品牌先行**："DEEPDIVE / 深潜" 占据视觉中心，字距即风格。没有导航栏、没有卡片、没有三列 feature 介绍——只有一个入口：「开始下潜」。
3. **截图即海报**：首屏任意时刻截图，构图都成立（品牌字安全区 + 光柱构图）。
4. **一句话钩子**（首屏文案，A/B 备选）：
   - "三个月前，萝拉·卡尔潜入寂静之井。昨天，她的手电还亮着。"
   - "洞里的导览线是新的。但没有人布过这条线。"
5. **声音钩子**：点击「开始下潜」瞬间，低鸣从脚底升起（Web Audio 需用户手势解锁，正好做成仪式感：按钮文案副行"戴上耳机"）。

## 2. 风格化钩子（可传播的视觉记忆点）

- **光锥美学**：所有宣传图统一构图——黑暗中一束暖光锥 + 光锥边缘的"某物"。形成可识别的视觉母题（类似《小小梦魇》的剪影记忆点）。
- **写字板梗**：手写体写字板天然是 meme 模板。"线是新的。我没布过这条线。" 这类短句可被二创替换。
- **三结局争论（v2）**：破晓 / 血里的针 / 浅睡——"你减压停做了吗？"会成为玩家互相拷问的暗号。**官方永不解释奇虾是什么。**
- **"你看清那个东西了吗？"**：silt-out 中的剪影目击刻意 <1.2 秒且看不清，逼玩家逐帧回放录屏、发帖对质——UGC 的经典引擎。
- **奇观截图链（v2）**：天光井光柱、光之烛台、卤水镜面、沉船肋骨、奇虾目击——五个"值得发图"的定机位，玩家自发形成打卡链。
- **"人为搞砸"话题钩（v2）**：搅浑的水、调转的箭头、被放空却重写标签的气瓶——"到底是谁在洞里？"是天然的讨论引擎；错绳死胡同里那只"不属于任何人的线轴"是二创母题。

## 3. 社交媒体转发机制

### 产品内机制（M2–M3 落地）
- **结局卡片**：通关生成竖版分享图——本次下潜数据（最大深度、剩余氧气、目击时心率峰值）+ 结局代号（「破晓」/「血里的针」/「浅睡」）+ 一句专属字幕。数据卡片天然适配朋友圈/小红书/X。
- **死亡地点即坐标**：缺氧结局显示"你停在 -37.2m"，可一键复制"我死在寂静之井 -37.2m，你能到多深？"——挑战式转发。
- **录屏友好**：惊吓段落前后自动保证画面无 UI 遮挡（HUD 淡出），玩家剪出的短视频干净可用。

### 平台策略
- **短视频（抖音/TikTok/B站）**：官方只发 15 秒切片——静默段+频闪目击，卡在目击帧结束。评论区问"你看到了什么"。
- **洞潜圈层**：真实洞潜模式（M4）是圈层敲门砖——邀请洞潜教练试玩并挑错，"游戏做对了三分法则"本身就是潜水社群的传播话题。技术准确 = 圈层尊重 = 自来水。
- **神秘学/怪谈圈层**：ARG 轻量化——萝拉·卡尔的"潜水日志"以图文连载形式先行发布，游戏是日志的"结局"。

## 4. 与洞潜圈/神秘事件热点的传播设计（伦理红线）

- 借力点是**洞潜文化本身**（导览线规范、写字板交流、"line arrow 指向出口"的生死常识），不是任何真实悲剧。
- **禁止**：影射真实遇难者、复刻真实事故时间线、使用真实洞穴事故名称做营销。
- **提倡**：内容物料中嵌入真实洞潜安全知识（"游戏里学到的三分法则是真的"），让传播自带正外部性；片尾致谢洞潜安全组织（虚构名义赞助位留白，M4 洽谈）。

## 5. 验收清单（M6）

- [ ] 首屏 3 秒截图测试：10 名陌生用户，≥6 人愿意转发
- [ ] 结局分享卡片生成率 ≥ 25%
- [ ] 15 秒官方切片完播率 ≥ 45%
- [ ] 洞潜社群试玩反馈：术语准确性零硬伤
