# 传播与恐怖/社交逻辑（Horror Design & Viral Strategy）

**项目：《回声园 / ECHO GARDEN》 · 原型阶段**

---

## 1. 恐怖设计哲学：三根支柱，零 Jump Scare

本作的恐怖不依赖突脸、巨响或怪物贴图。它建立在三根支柱上：

### 支柱一：信息不全（Epistemic Horror）

- 玩家永远只知道一部分：光柱之外是什么？敲击声是谁敲的？线为什么断？
- 实现载体：**深度触发的字幕碎片**（"你听见远处传来规律的、金属般的敲击声。三下。停。三下。"）、被改动过的线箭、"下面有光。那不该有光。"
- 纪律：**永远不解释。** 每个碎片都能自洽地被解读为自然现象或超自然现象——争论解读本身就是传播素材（见 §4）。

### 支柱二：不可逆的承诺（Commitment Horror）

- 每往下一米，都是用"回程的氧气"买的。恐惧不是"有东西追我"，而是**"我是不是已经回不去了"**——这是真实洞潜事故中最普遍的死因结构（超出折返点）。
- 实现载体：氧气单向消耗、导览线有限长度、越深越黑越窄、备用气瓶"捡了才有"的赌注感。

### 支柱三：身体化的资源（Somatic Horror）

- 恐惧要能被"听见"：呼吸声随氧量降低而急促、低氧心跳、黑视收束。玩家的身体状态被外化成音画，形成生理层面的紧张同步。
- 扬尘（silt-out）是"玩家自己制造的恐怖"：慌乱操作→能见度崩塌→更慌乱。**惩罚的是恐慌本身**，这正是洞潜训练的核心悖论，圈内人看到会会心一笑（可信度→转发）。

### 恐惧节奏曲线（一局 5–8 分钟）

```
入水(安全感) → 竖井(渺小) → 第一段字幕(不安) → 廊道收窄(压迫)
 → 敲击声字幕(悬疑峰值) → 深处之物(敬畏峰值) → 回程(全程光照闪烁,追赶感却无追赶者)
 → 出水/黑视(释放或落差)
```

## 2. 首屏/首分钟设计：让人一打开就截图

**目标：打开页面的第 3 秒产生第一次战栗，第 60 秒产生第一次"我必须发给朋友"。**

### 首屏（0–20 秒）：冷开场（已实现）

纯黑背景，六行文字逐行浮现（无音乐，只有静默）：

1. 本作灵感来自真实的洞穴潜水事故与真实存在的喀斯特地下河系统。
2. 出于对逝者与探洞者的尊重，地名、人物与数据均已虚构。
3. 在西南某地的甘蔗田之间，有一口没有名字的天窗。
4. 当地人叫它——**回声园**。
5. 最深的一次探测停在 **-214 米**。绳子在那里断了。
6. 今天，轮到你收回那段绳子。

→ 唯一按钮：**［ 戴上面镜 · 开始下潜 ］**
→ 页脚安全声明（真实感 + 伦理立场，本身即是可截图的传播物）。

**设计依据**：「真实事件改编」提示 + 具体数字（-214 米）+ 一个动词任务（收回绳子），是短视频开头留人率最高的三件套；"神秘园式"真实语境让洞潜圈与悬疑内容受众都能瞬间对号入座。

### 首分钟（20–80 秒）：坠入

- 点击按钮 → 直接入水，无教学关卡；操作提示只在 HUD 上淡淡一行；
- 前 15 秒还能看见头顶水面的日光光斑，一旦下潜光斑缩成"淡蓝色的硬币"——**第一次回头看不见入口的瞬间**，就是玩家的第一声"卧槽"；
- -12 米触发第一条字幕，字幕打字机音落在静默里；
- 玩家第一次贴墙扬起泥沙、光圈骤缩时，恐怖机制完成自我教学。

## 3. 社交钩子（Shareable Hooks）

### 钩子 A：每日洞穴（Daily Cave）——已实现

- 地图由**日期种子**生成：同一天全网玩家潜的是同一个洞（支持 `?seed=` 自定义挑战）。
- 天然产生可比较性："今天的洞穴 #20260825 你到了多深？" —— Wordle 式比较结构。

### 钩子 B：下潜日志分享卡——已实现（文本版）

一键复制、格式克制、带数字与悬念：

```
【回声园 · 下潜日志】洞穴 #20260825
▸ 最深 -138.4 m ／ 用时 06:12 ／ 第 3 次下潜
▸ 氧气余量 6%  ▸ 深处之物：已接触
▸ 结局：生还 ✔
同一天，所有人潜的是同一个洞。你能到多深？
```

死亡版结局行为"未归 ✘ ——线在 -97 m 处停了"，**死亡记录比生还记录更容易被转发**（幸灾乐祸 + 挑战欲）。P1 升级为可保存图片卡。

### 钩子 C："你敢一个人下去吗"挑战结构

- 游戏一局 5–8 分钟、浏览器即开，天然适配"发链接约战"；
- 面向主播/切片：黑暗 + 呼吸声 + 突然的字幕 = **表情失控时刻密集**，且无 jump scare 争议（不靠吓聋观众）。

### 钩子 D：洞潜圈内容共振（借势但不消费）

- 游戏机制本身是洞潜安全知识的隐喻（三分之一法则、慢就是快、线协议、silt-out）→ 可产出**科普向内容**："这个游戏里让你死的每一个机制，都是真实洞潜训练要解决的问题"；
- 邀请洞潜科普账号/技潜教练试玩点评，获得圈内可信度背书——**小圈层的认真讨论，是大圈层转发的引信**（2023 年都安事件的传播路径正是如此：圈内哀悼 → 全网科普 → 现象级关注）。

### 钩子 E：解读之争（ARG 化留白）

- "敲击三下"、编号 07 的线轮、"不要相信你的眼睛"刻痕——所有碎片刻意留出至少两种自洽解读；
- 评论区争论 = 算法燃料。后续版本可埋跨局一致性彩蛋（同一种子下碎片位置固定，可被"考据"）。

## 4. 传播矩阵与短视频脚本示例

| 渠道 | 内容形态 | 频率目标 |
|---|---|---|
| 抖音/快手/视频号 | 15–45s 竖屏切片（惊吓反应/科普/挑战） | 原型期 3 条打样 |
| B 站 | 3–8 分钟实况 + 洞潜科普联动 | 垂直切片期启动 |
| 小红书/微博 | 下潜日志截图 + "今天的洞穴"话题 | 每日种子驱动 UGC |
| itch.io / 独立游戏社区 | 可玩链接 + devlog | 原型即发 |

**脚本 1（悬念向，15s）**：黑屏白字"最深的一次探测停在 -214 米" → 头灯亮起画面 3 秒 → 字幕"下面有光。那不该有光。" → 卡断。文案："浏览器就能玩，别在半夜打开。"

**脚本 2（科普向，40s）**："洞潜为什么是最危险的运动？这个免费小游戏用 3 个机制讲明白了"——扬尘/折返点/导览线各给 8 秒实机。

**脚本 3（挑战向，20s）**：录屏氧气 2% 出水瞬间 + 日志卡截图："今天的洞穴 #20260825，我第 7 次才活着回来。你几次？"

**话题标签**：#回声园 #洞穴潜水 #你敢一个人下去吗 #每日洞穴 #海洋恐惧症慎入

## 5. 伦理红线（传播侧，硬约束）

1. **绝不使用真实逝者姓名/影像/事故现场素材**做任何营销物料；不投放任何"还原 XX 事故"类标题。
2. 借势真实事件仅限**科普与安全倡导**框架；所有物料带固定尾帧："真实洞穴潜水需要专业训练。请远离未开放水域。"
3. 不做"逝者视角"玩法营销；游戏内"回收潜水员"身份的表达以敬意为基调。
4. 若真实社群（洞潜圈、逝者亲友）提出不适，相关物料 24 小时内下架——**长期信誉比单条爆款值钱。**

## 6. 原型期传播验证指标（低成本）

- 链接打开 → 点击"开始下潜"转化率（首屏是否成立）；
- 一局完成率 / 平均重开次数（每日种子是否驱动重试）；
- 日志复制按钮点击率（分享钩子是否成立）；
- 3 条打样短视频的完播率与评论关键词（"敢不敢"、"真实事件"出现频次）。
