# 《蓝井》升级冲刺 — 奇观 · 互动 · EXE（2026-08 spectacle 线）

本轮目标：在 `cursor/deepdive-story-mode-cf93` 竖切基础上，把观感冲击力、可探索密度与
发布形态（Windows EXE）推到当前 Web/程序化管线的极限。分支：`cursor/deepdive-spectacle-exe-1a92`。

## 0. 痛点 → 对策总表

| 痛点 | 对策 |

| 材质达不到可发布精致度 | 洞壁 shader 注入：三平面细节法线扰动、湿岩镜面、岩层色带、方解石晶脉；焦散投影 |

## 1. 视觉奇观（Round A：渲染管线与材质）

### 1.1 后处理（post.ts）
- **Bloom**：亮通提取 → 1/4 分辨率两次可分离模糊 → 加性合成。高/中档开启，低档关闭。
  生物荧光、入口光柱、红房间辉光全部吃到光晕，是「PS5 感」的最大单项来源。
- **色分级升级**：深度驱动的水体吸收（红→绿→蓝逐级衰减）、split-tone（暗部青、亮部暖）、
  可调饱和度；红房间切换为红金色分级。
- 保留原有：水下扭曲/色偏/晕影收缩/颗粒/闪光/白光。

### 1.2 洞壁材质（cave.ts，onBeforeCompile 注入）
- **焦散**：入口段（浅水）世界空间动画焦散网纹，随深度衰减——「一眼震惊」首屏的关键。
- **细节法线**：程序噪声纹理三平面采样扰动法线，打碎低模平面感。
- **湿岩高光**：roughness 随噪声在 0.55–0.95 间变化，出现石壁湿反光。
- **岩层色带**：按世界 y 的窄带色相偏移（沉积层），凹陷 AO 加深。
- **生物膜**：发光廊道段（t 0.56–0.66）洞壁上翡翠色微弱自发光斑块。

### 1.3 入口奇观
- 光柱重构：更长更亮的体积锥 + 表面波光盘 + 焦散呼应；抬头能看到「一只慢慢合上的眼睛」。

## 2. 奇观场景（Round B）

- **穹顶大厅**（钟厅 t 0.30–0.50 升级）：半径加大；巨型晶柱（石笋石钟乳相连、微透光）；
  悬浮薄雾层（低速漂动的加性平面）；洞底「深渊开口」蓝黑渐变——壮美与恐惧同屏。
- **鱼群**（惊奇瞬间 ①）：钟厅 ~600 条程序化小鱼 instanced boids-lite，绕晶柱洄游；
  玩家靠近瞬间「银色爆散」+ 声浪，随后一道巨大阴影缓慢掠过穹顶（不显形，纯剪影+雾）。
- **生物发光廊道**（惊奇瞬间 ②）：割绳后 t 0.56–0.66，黑暗中洞壁缀满荧光生物；
  玩家游过时以到达波方式逐环点亮再熄灭（distance-band 脉冲），配 shimmer 声。
  美妙与压抑交替：廊道尽头重新跌回纯黑。
- **气室**（惊奇瞬间 ③，可选互动）：穹顶大厅顶部一处镜面「水膜」气穹——从水下仰望是一面
  抖动的镜子，映出手电光斑；靠近可听到瓮声回响与录音带里的水声。
- **红房间升级**：地板真镜面（平面反射相机）过重——改为强化镜像层 + 湿面高光贴图；
  帷幔双层视差；顶部环形吊灯；身影脚下波纹涟漪 shader。

### 3.2 案件档案 UI
- HUD 右上「档案 n/8」计数；收集时滑入通知。
- Tab（触屏「档案」按钮）打开档案面板：已收集线索列表 + 侦探批注，暂停游戏时间。

### 3.3 玩法决策
- **手电电量**：常亮约 9 分钟耗尽；关灯缓慢回充（省电决策）；电量 <25% 偶发闪烁（与脚本
  flicker 兼容，脚本优先）。惊吓段之后手电半亮已是既有设定，电量系统叠乘。
- **扬泥能见度**：贴近洞底高速游动 → 局部雾密度瞬时上升 + silt 颗粒增亮变浊，几秒内消散。
  教科书说「吐气、贴壁、慢」——现在真的要慢。
- **备用气瓶**：t 0.60 气瓶站可互动：检查发现只剩一口（+300 psi），拿或不拿都推进独白。
  缺氧段前的心理铺垫 + 数值决策。

## 4. Windows EXE（Round D）

- `vite-plugin-singlefile`：构建产出单文件 `dist/index.html`（全程序化、零资产，gzip ≈ 165KB）。
- **Go 便携宿主**（`exe-host/`）：`//go:embed` 单文件 HTML → 127.0.0.1 随机端口本地服务 →
  以 Edge `--app` 模式启动独立窗口（Win10/11 必装），窗口关闭进程即退出；找不到 Edge 时
  回退默认浏览器。`GOOS=windows GOARCH=amd64 -ldflags "-s -w -H=windowsgui"` 交叉编译，
  EXE ≈ 6MB，zip ≈ 3MB —— 直接进 repo `release/`，PR 内即可下载。
- `release/` 产物：`DeepDive-win64.zip`（EXE + 使用说明.txt + 网页备用 HTML）与
  `web/DEEPDIVE.html` 单文件网页版。
- `scripts/build-exe.sh` 一键重建；另保留 `scripts/package-electron-win.cjs`
  （PR #3 方案改造：官方 Electron zip 注入 dist，产出完整独立包 ~96MB，不入库）。
