# DEEP DIVE ·《蓝井》— 冲击力升级设计（v0.2 spectacle）

本轮目标：在故事模式竖切之上，把「观感冲击力」「可探索性」「玩法新鲜感」推到 Web 端可达的极限，
并在 PR 内提供可下载、双击直接游玩的 Windows 便携 EXE。

诚实约束：纯 Three.js + 程序化资产不可能字面等于原生 PS5 扫描资产；本轮以
**渲染管线（Bloom/HDR）、材质细节（湿岩/微表面/焦散/生物膜）、奇观编排（光柱/鱼群/发光廊道/逆浮水珠）、
节奏对比（壮美 ↔ 压抑）** 换取「一眼震惊」的整体观感。

---

## 1. 视觉提升项（渲染管线与材质）

| 项 | 方案 | 档位 |
|----|------|------|
| **Bloom 辉光** | 后处理新增阈值提取（soft-knee）→ 1/4 分辨率双向高斯模糊 ×2 → 线性 HDR 合成。所有发光体（光柱、荧光、LED、红房间高光）获得真实溢光 | 高=双迭代，中=单迭代，低=关 |
| **湿岩微表面** | 洞壁 `MeshStandardMaterial` 注入（onBeforeCompile）：世界空间三平面高频噪声扰动法线 + 湿润度图调制 roughness（0.9→0.3 补丁状），手电扫过时出现真实湿石高光 | 高/中全开，低仅湿润度 |
| **岩层地质分层** | 顶点色叠加沿地层轴的条带噪声（暖褐/冷灰/铁锈三色系），凹陷处 AO 加深 | 全档 |
| **焦散 caustics** | 入口区（世界 y > -26）洞壁/竖井注入两层错速滚动的程序焦散纹样，随深度衰减；模拟阳光透过水面的光斑舞动 | 高/中开，低关 |
| **水面仰视盘** | 入口顶部新增波动水面 shader 盘（从下往上看的明亮摇曳水面 + 菲涅尔亮斑），配合三根体积光柱与 Bloom 构成首屏震撼镜头 | 全档（低档简化） |
| **生物膜辉纹** | 发光廊道区间（t 0.58–0.74）洞壁顶点级生物膜掩码 → 注入脉动青紫辉光，与水螅体点阵共同构成「活的墙」 | 全档 |
| **色分级** | 保持深水蓝青分级；曝光/对比微调；红房间独立分级参数 | 全档 |

## 2. 奇观清单（≥3 个非惊吓的「令人惊奇」时刻）

1. **穹顶天光 + 银鱼漩涡**（钟厅 t≈0.36–0.46）：洞顶裂缝垂下一道巨大天光束（体积锥 + 真实聚光），
   一群银色小鱼绕光柱缓慢螺旋（实例化 + 逃散 AI：玩家冲入鱼群会四散再聚拢）。配乐 swell。
2. **生物发光廊道**（t≈0.575–0.68）：断线绝望之后，黑暗里浮现成千上万点青紫色水螅体。
   **关掉手电它们会更亮**（玩法教学与美学合一）；靠近墙面会激起一圈**光的涟漪**沿洞壁传播；
   可主动触摸（互动点）激发全廊道大波光。恐惧与美妙的第一次交替。
3. **深海生物・敬畏形态强化**（缺氧段）：躯干荧光带 + 呼吸式脉动辉光，Bloom 下如一座活的灯塔。
4. **红房间・逆浮水珠**（尾声）：对白「你带来了水」触发——数百颗水珠从地板缓缓**向上**坠落，
   在红色帷幔间闪烁（林奇式反物理奇观）。

## 4. 节奏（壮美 ↔ 压抑交替）

## 5. Windows EXE 方案

沿用并改进 PR #3 验证过的便携打包（Linux 上无需 Wine）：

1. `npm run build` 产出 `dist/`；
2. `scripts/package-win.cjs`：下载官方 Electron win32-x64（固定版本，`.cache/` 缓存）→
   解压 → 注入 `electron/main.cjs` 桌面壳 + `dist/` → `electron.exe` 改名 `DeepDive.exe` →
   裁剪 locales/非必需 DLL（**保留 ffmpeg.dll**，PR #3 踩坑点）→ 压缩为
   **`release/DeepDive-win32-x64.zip`**（<100MB，直接提交进仓库，PR 内可下载）；
3. 备用：`vite-plugin-singlefile` 产出单文件 `release/web/DEEPDIVE.html`（<1MB），
   Chrome/Edge 双击即玩（file:// 可用），覆盖无 Windows / 不敢运行 exe 的用户；
4. zip 内附 `使用说明.txt`（SmartScreen 应对、完整解压提醒、网页备用入口）。
