# 美术与资产设定（Art Direction & Asset Plan）

**项目：《回声园 / ECHO GARDEN》 · 原型阶段**

---

## 1. 风格关键词

> **"头灯光柱里的喀斯特" × "纪录片字幕" × "低保真克制恐怖"**

- **光是唯一的主角**：画面 90% 的时间是接近纯黑的，所有美术资源都为"光照到的那一小片"服务。玩家的头灯光锥就是镜头。
- **纪实感优先于奇观感**：岩壁、泥沙、导览线、气瓶都按真实洞潜影像的观感来做——恐怖来自"这看起来是真的"。
- **低保真是风格而非妥协**：原型采用程序化矢量绘制（Canvas 路径 + 渐变 + 粒子），刻意保留一点"声呐图/探测记录"的抽象感，与"信息不全"的恐怖主题互文。

---

## 2. 原型阶段资产精度（Asset Fidelity Bar）

**原则：零外部资源。** 原型中所有视觉与音频均由代码程序化生成，保证仓库轻量、加载即玩、风格统一。

| 资产类别 | 原型精度 | 实现方式 |
|---|---|---|
| 洞穴岩壁 | 瓦片级色噪 + 受光边缘线 | 每瓦片伪随机明度，邻水面瓦片描 1px 亮边 |
| 水体 | 深度映射的垂直渐变 + 悬浮微粒 | 颜色随深度从蓝绿压到近黑 |
| 光照 | 黑暗罩层 + 径向光晕 + 定向光锥（destination-out 挖洞） | 光半径受扬尘/事件调制 |
| 扬尘 | 赭色半透明粒子云，生长-漂移-消散 | 碰撞与高速触发 |
| 潜水员 | 程序绘制侧视小人：身体/背瓶/脚蹼/面镜/头灯，朝向光标旋转 | ~20 行 Canvas 路径 |
| 道具 | 气瓶（黄色高亮）、线箭、旧线轮、深处之物（脉动光球） | 简单几何 + 暗中微弱自发光 |
| UI | DOM + CSS，潜水电脑仪表风 | 等宽字体、扫描线、暗角 |
| 音频 | WebAudio 程序化合成 | 低频嗡鸣/呼吸/心跳/拾取音 |

**升级路径（P1 垂直切片起）**：手绘瓦片图集替换程序岩壁 → 骨骼动画潜水员 → 采样音效替换合成音。见 `WORKFLOW.md` 资产管线。

## 3. 氛围与调色板

### 3.1 情绪分层（随深度）

| 深度带 | 情绪 | 视觉处理 |
|---|---|---|
| 0 ~ -15m「入水」 | 平静、微凉 | 还能看见头顶水面的日光光斑（"淡蓝色的硬币"），水色 teal |
| -15 ~ -60m「竖井」 | 专注、渺小 | 光柱打不到对面岩壁，深蓝→墨蓝，微粒变多 |
| -60 ~ -120m「廊道」 | 压迫、幽闭 | 近黑，通道收窄，扬尘惩罚显著 |
| -120m 以下「园」 | 错误感、敬畏 | 接近纯黑 + 不该存在的苍白光源；触碰深处之物后全程光照轻微闪烁 |

### 3.2 核心色板

| 用途 | HEX | 说明 |
|---|---|---|
| 深渊底色 | `#010208` | 画面绝对基调 |
| 浅水 | `#0a3348` → `#04121d` | 深度渐变两端 |
| 岩壁 | `#11151a` ± 色噪 | 受光边缘 `#2e3d46` |
| 扬尘 | `#4a3b28`（α≤0.3） | 唯一的暖色污染 |
| 导览线 | `#aef78e` | 荧光绿，黑暗中的"生命线"，全画面最高识别度 |
| 气瓶/警示 | `#e8c33a` / `#ff4d4d` | 黄=资源，红=危险（仅 UI 与低氧状态使用） |
| 深处之物 | `#cfe3ff`（脉动） | 苍白、冷、"不像生物也不像灯" |
| UI 文字 | `#9fd8cf` | 潜水电脑荧光青 |

**纪律**：全局禁用饱和暖色（除扬尘与警示），让荧光绿导览线与黄色气瓶成为玩家视网膜上唯一的"锚"。

## 4. UI 方向

- **仪表化（diegetic 倾向）**：氧气条做成潜水电脑段码风格，深度/用时/线余量用等宽字体，低氧时数字闪烁 + 红移；
- **字幕即恐怖载体**：底部打字机字幕（逐字出现），是叙事碎片的唯一出口——克制、冷静、像探测日志；
- **无小地图、无指北针**：方向感缺失是核心体验，导览线就是唯一的导航 UI；
- **CRT 暗角 + 轻微扫描线**（CSS 实现），强化"记录仪画面"质感。

## 5. 角色与装备视觉方向

- 潜水员为**无面部特写的侧视剪影**：黑色湿衣、背瓶（P1 升级为侧挂双瓶 sidemount，更贴近洞潜真实配置）、长脚蹼、面镜玻璃一点冷反光、头灯为画面光源锚点；
- 呼吸排气泡是角色的"心跳可视化"：低氧时气泡串变密集；
- 深处之物**永不给出清晰轮廓**：只是光、以及光照不稳时的"负空间"。

## 6. 音频方向（原型已实现程序化版本）

- **床音**：46Hz 左右双振荡器失谐低鸣，随深度增益，像"洞穴的呼吸"；
- **玩家呼吸**：带通噪声脉冲，间隔随氧量降低而缩短——玩家会先"听见"自己紧张；
- **心跳**：低氧或触碰深处之物后启动，双击低频脉冲；
- **原则**：没有惊吓刺（stinger）、没有音乐旋律；寂静本身是最贵的音效。
