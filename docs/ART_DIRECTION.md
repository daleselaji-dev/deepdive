# DEEPDIVE · 美术方向与资产设定

> 一句话风格定义：**深渊青黑中的一束病态暖光。** 不是"蓝色海洋游戏"，是"手术灯照进墨水"。

---

## 1. 视觉支柱

1. **光即叙事**：全场景只有玩家手电 + 极少量剧情光源。光锥是玩家的"身体延伸"，也是恐惧的边界——看得见的地方安全，光锥边缘是舞台。
2. **体积压迫**：指数雾 + 悬浮颗粒（marine snow）让"水的厚度"可见。玩家永远感觉被包裹。
3. **错位的美**：构图追求安静的对称与仪式感（Hereditary 的画框感）；红厅段落直接转入林奇式舞台布光。
4. **反 AI 默认审美**：禁用紫白渐变、玻璃拟态卡片、奶油陶土 3D 图标。UI 是冷硬的仪表美学 + 手写体的人味。

## 2. 调色板

| 用途 | 色值 | 说明 |
|---|---|---|
| 深渊基底 | `#030a0d` | 近黑的青，所有画面的底色 |
| 水体雾色 | `#06181d → #041014` | 随深度变暗、变绿 |
| 手电暖光 | `#ffd9a0` | 色温 ~3400K，故意偏"旧灯泡" |
| 仪表琥珀 | `#e8a33d` | HUD 主色，潜水电脑表的复古琥珀 |
| 警示红 | `#c8341f` | 仅低氧与红厅使用，平时绝不出现 |
| 红厅帷幕 | `#5e0d0d / #8a1111` | 结局专用，天鹅绒质感 |
| 骨白 | `#e8e2d4` | 文字、写字板、目击者潜水服 |

**规则：琥珀与警示红不同时出现**（红一出现，琥珀 HUD 让位），保证"红=异常"的条件反射。

## 3. 光照设计

- **主光**：相机绑定 SpotLight（角度 ~28°，penumbra 0.6），带 0.15s 惯性延迟与轻微手持晃动——手电是"活的"。
- **补光**：极低强度冷环境光（`#0a2028`, intensity 0.12），只为让岩壁剪影可读。
- **剧情光**：入水段头顶下漏的青白光柱（god ray 面片）；井底红色水幕的脉动红光。
- **频闪脚本**：目击惊吓时手电以 70–140ms 随机间隔闪烁 6 次，第 3 与第 5 次之间插入目击帧。
- 色调映射：ACES Filmic，曝光 0.9，整体压暗宁欠勿过。

## 4. 材质与几何（程序化优先）

| 资产 | 做法 | 品质层级 |
|---|---|---|
| 洞穴隧道 | CatmullRom 样条 + 管几何体，顶点噪声位移出岩石起伏 | T0 程序化（现在）→ T1 雕刻高模烘焙（M3） |
| 岩壁纹理 | Canvas 合成噪声法线/粗糙度 | T0 → T1 KTX2 压缩扫描岩理 |
| 悬浮颗粒 | Points + 软圆 sprite，随水流缓漂 | 全层级保留，数量分档 |
| 导览线 | TubeGeometry 细管 + 自发光箭头标 | 全层级 |
| 写字板/气瓶 | 低模盒体 + Canvas 手写纹理 | T0 → T1 建模 |
| 目击者 | 拉长人形剪影（故意低细节，"看不清"是设计） | 永久低细节，这是风格 |
| 红厅 | 波动顶点着色帷幕 + 锯齿地纹 + 发光竹节虫（骨架化几何） | T0 → T2 影视级（M5） |

## 5. UI / 排印

- **HUD**：等宽字体（ui-monospace 栈），琥珀色，模拟潜水电脑表——氧气条是竖置圆柱刻度而非血条；深度以大号数字呈现。低氧时 HUD 加入随机字符抖动（仪表故障感）。
- **字幕/无线电**：衬线体（Georgia 栈），骨白，出现时带 1 帧错位残影。
- **写字板**：全屏化呈现，Canvas 手写纹理 + 水渍。
- **标题字**：超宽字距无衬线 "DEEPDIVE" + 竖排汉字「深潜」，压在动态 3D 首屏上；副标题 "寂静天坑事件"。
- 全局叠加：细颗粒噪点（film grain）+ 呼吸式暗角，透明度极低（≤6%）。

## 6. 性能与移动端适配策略

### 质量档

| 档位 | 目标设备 | DPR | 粒子 | 隧道分段 | 雾/光 |
|---|---|---|---|---|---|
| **Ultra** | 桌面独显 | ≤2.0 | 2400 | 1200×48 | 全效果 + 阴影（M3 起） |
| **High** | 桌面核显/高端手机 | ≤1.75 | 1200 | 800×32 | 全效果无阴影 |
| **Mobile** | 中低端手机 | ≤1.25 | 500 | 500×24 | 雾保留、god ray 减半 |

- 启动时按 UA + 屏幕 + `devicePixelRatio` 自动分档，允许 URL 参数覆盖（`?q=mobile`）。
- **LOD 路径（M5）**：隧道按相机距离分段隐藏（样条参数天然支持区间裁剪）；颗粒系统按档位缩池；写字板纹理按档位 1024/512/256。
- **移动端降级顺序**（帧率不达标时依次牺牲）：DPR → 粒子数 → 隧道分段 → god ray → 手电半径。**雾与手电永不裁掉**——它们是风格底线。
- 高端愿景（主机品质）：M5 引入 WebGPU 渲染管线分支、体积光 raymarch、SSAO；移动端保持当前管线。

## 7. 资产清单（原型 T0，全程序化，零外部文件）

- 几何：隧道样条管 ×1、岩石凸起实例 ×N、导览线管 ×1、写字板 ×5、气瓶 ×2、目击者剪影 ×1、红厅（帷幕 8 片、地面、竹节虫）
