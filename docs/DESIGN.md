# DEEP DIVE ·《蓝井》— 设计文档

浏览器可玩的第一人称「洞潜 / 深海洞穴调查」叙事恐怖游戏。
本文档覆盖：游戏设计、场景节拍表、技术架构、画质档位、以及「真实洞潜模拟模式」的扩展点。

---

## 1. 高概念

> 一个不会洞潜的私家侦探，为了一盘录满水声的磁带，潜入了「蓝井」。

- **类型**：第一人称叙事恐怖 / 步行（游泳）模拟 / 侦探噩梦
- **参照系**：
  - 恐怖节奏 —《遗传厄运》(Hereditary)：长时间的不安静默、环境异常的缓慢积累，惊吓只在叙事充分铺垫后出现一次，且必须"值得"。
  - 叙事气质 — 大卫·林奇《穆赫兰道》/《双峰》：侦探框架逐渐溶解为梦逻辑；结局进入红房间式超现实空间。
  - 点睛 —《极乐迪斯科》竹节虫：恐怖的对象最终以"巨大、平静、非人却并无恶意"的方式现身，把惊吓转写为敬畏。
- **平台**：纯前端 Web（Three.js / WebGL2），零安装，桌面键鼠 + 移动端触控。
- **资产策略**：100% 程序化（样条隧道几何 + 噪声置换、Canvas 程序纹理、GLSL 后处理、WebAudio 合成音频）。仓库无二进制资产。

## 2. 故事梗概（故事模式竖切）

委托人是个不肯摘手套的男人。他的哥哥**埃利亚斯·凡恩**（Elias Vann），职业洞穴潜水员，三周前在雾季小镇的天坑「蓝井」下潜后失踪。他寄给弟弟的最后一件东西是一盘磁带：四十分钟的水声——第三十九分钟，有人在水里说话。

主角（玩家）不会洞潜，但接了案子。整个游戏是一次下潜：跟随前人布设的主线绳深入，收集埃利亚斯留下的痕迹（铭牌、仍在闪烁的潜水电脑、被"整齐割断"的线绳），穿过挤压段进入无光区。手电熄灭、假的"指引灯"出现又熄灭——在完全的黑暗与心跳声之后，手电回光的一瞬，**那张苍白的脸**就在面前（唯一一次 jump scare，铺垫完毕才发生）。气瓶被撞裂，氧气泄漏。

濒临缺氧时，**深海生物**再次出现——这一次它巨大、缓慢、周身生物荧光，平静地注视着玩家，并"说话"（竹节虫式的点睛）。视野在它的光里收束（结局 a：缺氧收束）。

黑暗之后，玩家在**红房间**醒来：红色帷幔、之字形地板、一个背对着的潜水服身影。林奇式的对话之后，灯光熄灭，结案报告：未提交。（结局 b：红房间超现实收尾）

> 竖切中两个结局串联为一条完整叙事弧：缺氧收束 → 红房间尾声，保证至少一个完整可到达结局。

## 3. 场景节拍表（以线路进度 t ∈ [0,1] 驱动）

| # | 节拍 | t 区间 | 空间 | 氛围/机制 | 音频 |
|---|------|--------|------|-----------|------|
| 0 | 序幕 | — | 黑屏介绍卡 ×4 | 侦探独白，打字机文本 | 磁带底噪 |
| 1 | 入水 | 0–0.12 | 竖井入口，上方光柱 | 教学（移动/升降/手电/跟线），高能见度、蓝绿色调、体积光 | 轻环境 drone、呼吸循环 |
| 2 | 咽喉 | 0.12–0.30 | 通道收窄 | 雾变浓、色调转冷；**线索1**：线绳上的铭牌 "E.V." | 远处单次金属敲击 + 洞穴混响 |
| 3 | 钟厅 | 0.30–0.50 | 大厅、石笋石钟乳 | 开阔感反差；**线索2**：仍在闪红灯的潜水电脑 | 三次金属敲击后静默；无线电杂音 |
| 4 | 窄缝 | 0.50–0.65 | 最窄挤压段 | 呼吸变重、心跳出现；**线索3**：主线绳被整齐割断（导航失效，方向迷失感） | 呼吸加速、心跳、drone 降到次声感 |
| 5 | 异象 | 0.65–0.78 | 无光区 | 手电闪烁；远处出现第二盏"指引灯"，靠近即灭 | 回声异常（气泡延迟回放）、高频耳鸣音 |
| 6 | 惊吓 | ≈0.78 | 原地 | 手电熄灭→3 秒纯黑+心跳→两下叩击→手电回光一瞬：**苍白的脸**，随即黑暗；气瓶破裂 | 惊吓 stinger（合成）、气泡狂涌 |
| 7 | 缺氧 | 0.78–0.95 | 上升段 | 视野收缩（隧道视觉）、声音闷化、行动迟缓；**深海生物**平静现身并"说话" | 声场低通、心跳减慢、超现实 pad 渐入 |
| 8 | 红房间 | 尾声 | 独立场景 | 步行模式；红帷幔、之字地板、镜面反射、背对的身影；对话后收束 | 颤音和弦 pad、林奇式静默 |

Jump scare 军规：只此一次；此前必须已经完成 —— 灯光异常（≥2 次闪烁）、指引灯出现又熄灭、≥3 秒完全黑暗、心跳与呼吸加速、叩击声铺垫。禁止无铺垫惊吓。

## 4. 核心玩法循环

- **游动**：全 3D 六自由度（WASD + Space/Shift 升降 + 鼠标视角；移动端双摇杆+按钮）。速度慢（≤2.2 m/s），带惯性与水阻，轻微浮力摆动。
- **灯**：手电（聚光灯 + 体积光锥 + 近距补光），可开关（F）；脚本可接管（闪烁/熄灭/回光）。
- **氧气**：压力表（psi）持续消耗，受用力与紧张度影响；竖切为叙事节奏服务（低氧演出由脚本驱动，破瓶后进入不可逆的缺氧序列）。
- **线绳导航**：主线绳沿隧道下侧铺设，是唯一可靠的导航物；t=0.55 处被割断，之后玩家被迫"离线"前进 → 方向迷失感。
- **环境互动**：视线中心射线检测（E / 触控按钮），阅读线索并推进独白。
- **叙事触发**：进度 t 驱动的触发器表（雾密度、drone 强度、心跳、事件、字幕、目标提示）。

## 5. 技术架构

```
src/
  main.ts                 # 引导：renderer / 主循环 / resize
  core/
    quality.ts            # 画质档位（High/Medium/Low + 自动检测，移动端默认低档）
    input.ts              # 键鼠 + 指针锁 + 触控（虚拟摇杆/按钮）统一输入
    audio.ts              # WebAudio 全程序化合成（drone/呼吸/心跳/敲击/stinger/pad/混响）
    noise.ts              # 种子随机 + Simplex 3D + fbm（几何与纹理共用）
  render/
    post.ts               # 自研单通道后处理：水下扭曲/色偏/色分级/晕影(缺氧收缩)/颗粒/闪光/淡出
    particles.ts          # 悬浮微粒（相机周围循环体）+ 气泡池（呼气/破瓶喷涌）
    volumetric.ts         # 加性体积光锥（手电/入口光柱）+ 程序化辉光片
  game/
    modes.ts              # GameMode 接口 + 模式注册表（story 可玩 / sim 预留）
    game.ts               # 编排器：菜单→介绍卡→游玩→暂停→致谢 状态机
    story/
      cave.ts             # 程序化洞穴：样条+半径剖面+噪声置换管状几何、线绳、石笋、线索道具
      storyMode.ts        # 玩家控制、氧气、脚本引擎、惊吓/缺氧序列、场景切换
      script.ts           # 节拍表数据（触发器 + 全部叙事文本）
      creature.ts         # 深海生物（苍白脸 + 蛇形躯干 + 生物荧光，菲涅尔皮肤 shader）
      redroom.ts          # 红房间：帷幔波动 shader、之字地板、镜面地面、身影、对话
  ui/
    hud.ts                # 氧气表/深度计/字幕/目标/交互提示/介绍卡/致谢/淡入淡出
    menu.ts               # 标题菜单（模式选择、画质、操作说明）
```

- **渲染管线**：场景 → WebGLRenderTarget → 全屏合成 shader（一次后处理通道，低端机降分辨率）。ACES 色调映射；FogExp2 按节拍插值密度与色相。
- **碰撞**：沿样条预采样 1200 个 `{中心, 半径}`；每帧就近采样（局部搜索）并把玩家径向位置钳制在 0.62×半径内 —— 廉价且不可能穿墙。进度 t 即最近采样索引。
- **音频**：无任何采样资产。卷积混响的脉冲响应也由噪声程序生成（洞穴回声）。母线低通滤波实现缺氧"闷化"。
- **文本**：全部字幕/UI 为简体中文，衬线字体 + 字距排版。

## 6. 画质档位

| 档位 | 像素比 | MSAA | 微粒数 | 体积光锥 | 后处理 | 隧道细分 |
|------|--------|------|--------|----------|--------|-----------|
| 高   | ≤2.0   | RT 4x | 2600 | 全开 | 全效果（扭曲/色偏/色分级/晕影/颗粒） | 720×30 |
| 中   | ≤1.5   | 关 | 1200 | 开 | 无色偏 | 520×24 |
| 低   | 1.0    | 关 | 500  | 关（保留入口光柱简化版） | 色分级+晕影+颗粒 | 360×18 |

自动检测：触屏设备 → 中（≥6 核）或低；桌面 → 高。菜单与暂停菜单均可切换。

## 7. 模式架构与「真实洞潜模拟模式」扩展点

`game/modes.ts` 定义：

```ts
interface GameMode {
  readonly id: string;
  init(ctx: GameContext): Promise<void> | void;
  update(dt: number): void;
  dispose(): void;
}
```

编排器只依赖该接口。竖切实现 `StoryMode`；`SimMode` 以"预留席位"注册（菜单可见、标注 v0.2）。计划中的模拟模式复用同一套洞穴生成/渲染/音频，仅替换规则层：

- **气体管理**：三分法则（1/3 进、1/3 出、1/3 冗余）、可选双瓶/侧挂、气体切换与减压停留；
- **导航**：真实布线（放线轮、方向标 line arrow、跳线 jump），断线时的摸线搜索协议；
- **能见度**：淤泥扬起（percolation / silt-out）动态能见度模型，鳍法选择影响扬泥量；
- **失误链**：面镜进水、灯故障（主灯+两备灯）、缠绕解脱；
- **无脚本**：钟厅之后的洞穴改为种子随机生成（`cave.ts` 已按"样条+半径剖面"参数化，可直接喂随机剖面）。

## 8. 音频设计（全合成）

| 声音 | 合成方式 |
|------|-----------|
| 环境 drone | 双失谐低频振荡器 + 布朗噪声低通，强度由脚本插值 |
| 呼吸循环 | 带通噪声扫频（吸气）+ 正弦 blip 簇（呼气气泡），周期随紧张度缩短 |
| 心跳 | 55Hz 正弦双击，速率/音量由紧张度与氧量驱动 |
| 金属敲击 | 非谐波分音簇（1, 2.76, 5.40, 8.93 倍频）+ 程序化卷积洞穴混响 |
| 惊吓 stinger | 失谐锯齿簇下滑 + 高通噪声爆发 + 次低频下坠，经波形整形失真 |
| 红房间 pad | 小调和弦正弦簇 + 慢速颤音 + 音分漂移（磁带感） |
| 缺氧 | 母线低通 20kHz→300Hz + 心跳减速 |

## 9. 竖切验收标准

- `npm install && npm run build` 成功；`npm run dev` 可玩。
- 完整叙事弧：入洞 → 压迫深入 → 异常 → 铺垫后的惊吓 → 缺氧收束 → 红房间结局 → 回到标题。
- 键鼠 + 触控均可完成流程；三档画质可切换。
- 首屏（入水一刻）具备"一眼震惊"的氛围完成度：光柱、微粒、雾、色分级、颗粒。
