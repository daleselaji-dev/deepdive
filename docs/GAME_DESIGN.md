# DEEPDIVE · 游戏设计文档（v2 · 深渊奇观版）

> 类型：洞穴潜水 · 侦探悬疑 · 心理恐怖 · 水下奇观
> 一句话：**一名前警队潜水员潜入天坑洞穴调查失踪的传奇洞潜员——越往深处风景越震撼、越往深处越确定：这口井的最深处，游着一条不该存在于这个纪元的东西。**

---

## 0. v2 升级纲领（本轮迭代的最高准则）

1. **一眼震惊**：首屏即奇观——从井底仰望，阳光穿过水面洒成光柱，鱼群绕柱回游，头顶是支援船的黑色船底剪影。
2. **美妙风景 + 真实压抑恐惧并存**：每个区域都要有一个"值得截图"的视觉高潮点，同时压抑感随深度线性增长。
3. **越深越多，不只是通道**：探索要素密度随深度递增（写字板、气瓶、生态、地标、互动物件、支线岔路）。
4. **结局改版**：删除「红厅/竹节虫」超现实结局，改为**远古生物目击（奇虾 Anomalocaris）+ 完整上潜回船流程**。
5. **机制精密**：氧气、氮饱和/减压停、导览线、备用气瓶、上潜/下沉的完整生死闭环。

---

## 1. 核心概念

### 1.1 恐怖哲学（不变）

- **《遗传厄运》**：恐惧来自"注意到角落里一直有东西"。惊吓之前是漫长的平静。
- **林奇式错位**：熟悉事物以微妙错误的方式出现——箭头指向洞里、无线电里的"自己"。
- **《深海迷航》**：深度本身即恐惧，且**深度本身即奇观**。玩家自愿往下游。

### 1.2 三层结构（v2 调整）

1. **生理层**：氧气递减 + 氮气累积。呼吸、心跳、减压表——"诚实的恐惧"。
2. **环境层**：洞穴不对劲（人为搞砸的痕迹：搅浑的水、调错的线、空的备用瓶）。
3. **奇观层**（v2 新增，替代原"存在层"）：深渊的尽头不是怪物袭击，是**目击**——一只五亿年前的生物安静地游过，它不攻击、不解释，它只是在。恐惧升华为敬畏。

## 2. 地图设计 ·「寂静之井」v2

### 2.1 拓扑：闭环 + 岔路

地图为**一条闭环主脉 + 2 条支线岔路**，不是线性管道：

```
        水面(0m)·支援船
           │
      Z1 天光井 (0–12m) ◀───────────────┐
           │                            │
      Z2 石笋回廊 (12–18m)              │
           │                            Z9 回程烟囱
      Z3 咽喉 (18–24m)                  │ (48m→8m 螺旋上升)
           │                            │
      Z4 光之厅 (24–28m)                │
           │                            │
      Z5 卤水镜面 (28–33m)              │
           │                            │
      Z6 沉船祭坛厅 (33–38m) ─ 支线A：玛雅祭坛壁龛
           │                            │
      Z7 塌方段 (38–42m) ─ 支线B：错绳死胡同
           │                            │
      Z8 深渊大厅 (42–48m) ─────────────┘
          （远古生物目击点）
```

**去程走左脉（Z1→Z8），高潮后从 Z9 烟囱环回天光井上潜**——玩家不需要原路折返，回程是全新的垂直风景。

### 2.2 分区细设（每区一个视觉高潮点 ★）

| 区 | 深度 | 内容与探索要素 | ★ 视觉高潮 |
|---|---|---|---|
| **Z1 天光井** | 0–12m | 入水竖井。水面在头顶波动，支援船船底剪影，鱼群绕光柱回游（靠近会散开）。写字板#1。 | ★ 仰望：太阳穿水面成光柱簇 + 焦散纹在岩壁流动 |
| **Z2 石笋回廊** | 12–18m | 钟乳石/石笋/石柱阵，导览线起点。写字板#2。 | ★ 手电扫过石柱林的纵深剪影 |
| **Z3 咽喉** | 18–24m | 收窄挤压段，气泡沿顶壁走。第一个备用气瓶。 | ★ 回头看——来路的光已成远处一粒 |
| **Z4 光之厅** | 24–28m | 大厅。顶部裂隙漏下第二道细光束，正打在一座石笋塔尖。盲眼小鱼群。写字板#3。 | ★ 黑暗大厅中央一根"光之烛台" |
| **Z5 卤水镜面** | 28–33m | 硫化氢卤水云层——洞中之湖的"假水面"，枯树枝从雾面伸出。穿过时能见度骤降。备用气瓶#2（**空的**，剧情）。 | ★ 悬停在乳白雾湖上，倒影里是自己 |
| **Z6 沉船祭坛厅** | 33–38m | 半个世纪前的木质补给船残骸（肋骨状船架、散落陶罐）。支线A：玛雅祭坛壁龛（雕纹石碑 + 玉石供品，可交互发光）。写字板#4、#5。silt-out 事件。 | ★ 手电照亮沉船肋骨的瞬间 |
| **Z7 塌方段** | 38–42m | 巨石阵塌方，主线断裂。支线B：一条"新线"通向死胡同（错绳事件）。写字板#6。备用气瓶#3。 | ★ 断线的线头在水流里缓慢摆动 |
| **Z8 深渊大厅** | 42–48m | 最大空间，中央是坠向纯黑的深井断崖。发光水母群缓慢漂移，浮游生物被扰动时脉冲发光。**远古生物目击**。写字板#7（萝拉最后的记录）。备用气瓶#4。 | ★★ 奇虾从深井中升起、横越大厅、沉回黑暗 |
| **Z9 回程烟囱** | 48→8m | 目击后蓝色微光标出烟囱入口，螺旋上升回天光井。上升途中氮饱和警告、减压停留。 | ★ 上升中头顶的光斑越来越大，最后炸成整面水面 |

### 2.3 探索密度曲线（"越深越多"）

- Z1–Z3（浅）：写字板×2、气瓶×1、鱼群×1 —— 熟悉操作。
- Z4–Z6（中）：写字板×3、气瓶×2（其中一空）、生态×2、地标×3、支线×1、事件×1。
- Z7–Z8（深）：写字板×2、气瓶×2、生态×2、地标×2、支线×1、事件×1、**生物高潮**。

## 3. 结局设计（v2 · 全部重做）

> **明确移除**：红厅、竹节虫、Twin Peaks 引用。深渊的尽头不再是超现实房间。

### 3.1 高潮 ·「目击」（非结局，流程转折点）

玩家进入 Z8 深渊大厅中心：环境音撤走 → 亚低频震动由远及近 → 深井里升起**奇虾（Anomalocaris）**——体长十余米（不该有的尺寸），侧鳍波浪状推进，一对前附肢蜷在口前，柄眼在手电光里反出两粒冷光。它横越大厅，不看你，或者看了你一眼（柄眼转向玩家 1.5 秒），沉回深井。字幕：

> "它比这座山更老。它见过第一缕照进这口井的光。"
> "你忽然明白萝拉为什么不回来了——有些东西，看过一眼就值了。"

之后蓝光标出回程烟囱，无线电恢复：**上潜阶段开始**。

### 3.2 结局 E1 ·「破晓」（完整上潜回船）

Z9 烟囱上升 → 深度回到 5m 时 HUD 弹出**减压停留**（-5m · 倒计时，服务紧张感：氧气还在掉）→ 完成后继续上升 → **破水面**（音景瞬间切换：闷水声换成风、虫鸣、水花）→ 水面泳向支援船 → 靠近船舷触发登船 → 结局画面（黄昏天空、统计、萝拉案件的收尾文本）。

### 3.3 结局 E2 ·「血里的针」（减压病变体）

氮饱和高（深处逗留过久/上升过快）且**跳过减压停留**直接破水面：登船成功但结局文本转暗——关节的针刺、咳出的粉红泡沫、"你把深渊带上来了一点"。不是死亡，是代价。**轻度机制，服务叙事**：只影响结局文本与登船演出（视野晃动、色偏），不做数值惩罚。

### 3.4 结局 E3 ·「浅睡」（缺氧下沉，保留并强化）

任意时刻氧气耗尽：视野管缩 → 操控失效 → **身体开始下沉**（相机缓慢坠向下方黑暗，marine snow 相对上升）→ 手电变暖 → 黑。字幕保留原文案。下沉过程加深度计还在跳的细节（-49.2…-50.1…）。

## 4. 精密潜水机制（v2）

### 4.1 氧气（主时钟）

- 基础消耗 100/420s（约 7 分钟），冲刺 ×2.2。
- 备用气瓶 ×4（+35 each），其中 Z5 一只是**空的**（剧情事件，标签写满压）。
- 低氧 <30%：心跳入场、HUD 颤动；<12%：视野收缩；0%：结局 E3。

### 4.2 氮饱和 / 减压（轻度机制）

- 深度 >18m 时氮值缓慢累积（越深越快）；<10m 缓慢释放。
- HUD 细条显示（琥珀→红）。上潜阶段在 -5m 触发**减压停留提示**（约 40 秒游戏时间）。
- 高氮 + 跳过停留 = 结局 E2 变体；完成停留 = E1。**无即死惩罚。**

### 4.3 导览线（导航主轴）

- 主线沿全程，箭头方向是剧情道具（被人调转）。
- 回程阶段 HUD 增加"沿线方向"提示；silt-out 事件中导览线是唯一参照。

### 4.4 上浮/下沉物理

- 微负浮力常在；缺氧后浮力失控下沉。
- 去程阶段水面附近有涌浪压制（无法提前上浮，M 的无线电给出理由）；回程解锁。

## 6. 剧情模式 · 传播要素（v2 扩展）

红线不变：**全虚构，不影射真实遇难者与事故**；对洞潜技术文化保持准确尊重。

### 6.1 "人为搞砸"事件链（易传播的诡异感）

| 事件 | 位置 | 呈现 |
|---|---|---|
| **搅浑水** | Z6 沉船厅 | 前方忽然腾起沉积物幕墙，能见度跌至 1m（雾密度脉冲+棕褐色调）。无线电：'保持中性浮力，别踢底。'——**你没踢底。是谁踢的？** |
| **错绳** | Z7 支线B | 一条崭新的白线接在断口上，箭头指向死胡同；尽头挂着一只不属于任何人的线轴。写字板#6：'我的线是蓝的。' |
| **空气瓶** | Z5 | 标签手写"满 200bar"，拾取时压力表归零的特写音效。'有人放空了它，然后把标签擦干净重写。' |
| **矛盾写字板** | 全程 | 萝拉的字迹从工整到潦草；#5 与 M 的无线电内容直接矛盾（M 说"她没带写字板"）。 |
| **可疑无线电** | 全程 | M 知道只有下面的人才知道的事（"绕过那根断柱"——你还没报告断柱）。回程阶段 M 的声音混入第二层延迟回声。 |
| **减压隐患** | Z9 | 萝拉的减压表卡在 -5m 停留位挂在线上——她完成了停留，却没上船。 |

### 6.2 真实潜水细节（洞潜圈认可度）

三分气规则（无线电开场提及）、导览线箭头/线轴/cookie 标记、写字板交流、备用气瓶 staging、减压停留、silt-out 应对（沿线摸回）、水面支援船与入水检查对话。

## 7. 节奏图（v2 完整流程 ≈ 12–16 分钟）

```
入水(美) → 回廊(静) → 咽喉(压) → 光之厅(美↑) → 卤水(诡) → 沉船(惊·silt-out)
→ 塌方(乱·错绳) → 深渊(敬畏★目击) → 烟囱上升(希望+氮压) → 减压停(最后煎熬)
→ 破水面(释放) → 登船(结局)
        任意时刻缺氧 → 下沉(E3)
```

惊吓原则不变：一章一硬惊（silt-out 中的剪影目击），其余全是假警报与暗示。
