# 游戏设计规划（Design Plan）

**项目代号：《回声园 / ECHO GARDEN》**
**类型：洞穴潜水 · 生存探索 · 氛围恐怖（Atmospheric Horror）**
**阶段：原型（Prototype / MVP）**

---

## 1. 一句话概念

> 在一口以真实喀斯特天窗群为原型的水下洞穴里，你带着有限的气体、一卷导览线和一支头灯，独自下潜去收回一段"断掉的绳子"——而深处有什么东西，比你更早知道你会来。

《深海迷航》(Subnautica) 给了我们"未知水域的敬畏与恐惧"这一情绪母题；本作把它压缩进一个更幽闭、更垂直、更贴近真实洞潜体验的空间里：**没有开阔海面，只有岩壁、悬浮的泥沙、和一条回家的线。**

---

## 2. 核心背景设定

### 2.1 世界观（虚构层）

西南某地的甘蔗田与峰丛之间，散布着一片相互连通的地下河天窗群。其中一口没有正式名字的竖井，因为"喊一声，回音会分成好几层、从不同方向回来"，被当地人称作**「回声园」**。

- 多年来，探洞与技术潜水团队在此逐段布线，最深探测记录停在 **-214 米**——那一次，主导览线在深处被"某种东西"割断，团队按协议放弃了末段绳线撤出。
- 玩家扮演一名回收潜水员（recovery diver），任务只有一个：**下到断线处，收回属于前人的那段线。**
- 游戏不解释深处到底有什么。所有超自然元素都停留在"信息不全"的层面：敲击声、不该存在的光、被改动过的线箭。**玩家看到的越少，脑补的越多。**

### 2.2 情绪基调

- **敬畏，而非猎奇**：洞穴不是怪物巢穴，它是一个古老、中性、不在乎你的空间。恐惧来自"我不属于这里"，而不是"有东西要吃我"。
- **纪录片质感**：冷静的字幕、真实的技术潜水术语（导览线、线箭、气瓶余量、扬尘），让玩家感到"这一切规则是真的"。

## 3. 真实灵感来源（及尊重原则）

本作的地形、规则与事件语境参考了以下真实地区与公开报道的真实事件。**所有地名、人名、数据在游戏内均已虚构化处理。**

### 3.1 真实地区原型

| 原型 | 说明 | 在游戏中的映射 |
|---|---|---|
| 广西都安 · 地苏地下河系统 | 世界级喀斯特地下河，数百个"天窗"（垂直溶井）串联，是国内技术洞潜的核心热点区 | 「回声园」天窗群的整体地貌：甘蔗田间的垂直竖井 + 深部水平廊道 |
| 广西都安 · 九顿天窗 / 神秘园天窗 | 国内最著名的深洞潜点，多次刷新亚洲洞潜深度纪录；"神秘园"这一名字本身即是圈内热点符号 | 游戏标题与核心意象「回声园」即对「神秘园」的虚构化致意；-214 米的"断线深度"为虚构数字 |
| 墨西哥尤卡坦 · Sac Actun 水下洞穴系统 | 世界最长水下洞穴，玛雅"献祭井"传说与考古发现并存 | "深处曾有人来过"的考古感叙事碎片（刻痕、旧线轮） |
| 美国佛州 Eagle's Nest / 南非 Boesmansgat | 以"美丽且致死"著称的深潜点 | 洞口"警示牌"式的开场文案传统 |

### 3.2 真实事件语境（仅作语境参考，绝不复刻）

- **2023 年广西都安洞潜事故**（知名洞潜运动员在九顿天窗深潜中失联遇难，引发全网对"洞潜"这一小众圈层的空前关注）——本作只借用该事件揭示的**公众情绪结构**："普通人第一次意识到，地图上一个不起眼的水塘下面，可能是几百米深的垂直深渊。"
- **Nutty Putty 洞穴事故（美国犹他州，2009）**、**Plura 洞穴事故（挪威，2014，后改编为纪录片《Diving into the Unknown》）**、**Dave Shaw 遗体回收事件（南非 Boesmansgat，2005，纪录片《Dave Not Coming Back》）**——"回收潜水员"这一玩家身份即来自真实洞潜圈最沉重也最崇高的传统：**去把人（或他的绳子）带回来。**

### 3.3 尊重原则（红线，全阶段有效）

1. **不使用任何真实逝者的姓名、肖像、可辨识细节**；不复刻任何一场具体事故的过程。
2. **不把真实悲剧写成"怪物害的"**——超自然元素只存在于虚构的「回声园」，与任何真实事件解耦。
3. 游戏内外所有物料附带安全声明：**"真实洞穴潜水需要系统训练与专业装备。永远不要在未受训练的情况下进入水下洞穴。"**
4. 传播物料引用真实事件时只做**科普向、致敬向**表达（详见 `VIRAL_SOCIAL.md` 伦理红线一节）。

## 4. 核心玩法循环（Core Loop）

```
 布线下潜 ──▶ 管理资源（气体/导览线/能见度）──▶ 抵达更深处 / 获得叙事碎片
    ▲                                                    │
    │                                                    ▼
 复盘分享 ◀── 生还结算（下潜日志） ◀── 沿线返回（或死在下面）
```

分解为三层张力：

1. **每一秒的张力 —— 气体与能见度**
   - 氧气持续消耗，运动越剧烈消耗越快；
   - 贴近岩壁或高速移动会**扬起泥沙（silt-out）**，能见度骤降，头灯光圈缩小；
   - Shift 缓速潜行可减少扬尘——"慢就是快"是真实洞潜的铁律，也是本作的操作深度来源。
2. **每一分钟的张力 —— 不可逆的深度承诺**
   - 越深越黑、越窄；备用气瓶（stage tank）沿主通道预置，捡或不捡、什么时候折返，全是玩家自己的决定；
   - 导览线长度有限（约 200 米），线放完了还往里游，就是在赌命。
3. **整局的张力 —— 未知深处**
   - 深度触发的叙事碎片（字幕）逐步递交"信息不全"的恐怖；
   - 最深处有一个**发光的"深处之物"**：触碰它是唯一的"任务完成"条件——然后你还得活着回去。

**一局时长目标：5–8 分钟。死亡重开成本低，地图当日固定（每日种子），鼓励重复挑战与社交比较。**

## 5. 原型范围（MVP，本仓库已实现）

| 模块 | MVP 实现 | 说明 |
|---|---|---|
| 地图 | 程序化生成的垂直洞穴（每日种子固定，支持 `?seed=` 覆盖） | 主竖井随机游走下行 + 侧向支洞 + 气室（air bell） |
| 移动 | 惯性游泳、圆形碰撞、Shift 缓速 | 鼠标控制头灯朝向 |
| 氧气 | 持续消耗 + 运动加成消耗；备用气瓶 +40%；气室缓慢回气；水面无限 | 归零→黑视→死亡结算 |
| 能见度 | 深度衰减的黑暗 + 头灯光锥 + 扬尘系统（碰撞/高速触发，局部降低光照半径） | 恐怖体验的物理载体 |
| 导览线 | 自动布线、总长约 200m、沿线回望箭头、余量显示 | 迷路恐惧的解药与计量器 |
| 叙事 | 深度触发字幕 + 实体触发字幕（线箭/刻痕/旧线轮）+ 深处之物事件 | 打字机字幕，信息不全式恐怖 |
| 结算 | 生还/未归两种结局；下潜日志（最深、用时、余气、次数）一键复制分享 | 社交钩子落地 |
| 音频 | WebAudio 程序化：低频洞穴嗡鸣、呼吸循环（随氧量加速）、低氧/回程心跳 | 无任何外部音频资源 |
| 技术栈 | 纯 HTML/CSS/JS + Canvas 2D，零依赖零构建，双击即开 | 见 `prototype/` |

### MVP 明确不做

- 3D / WebGL、真实水体模拟、装备配置系统、多结局分支、存档、移动端适配、成就系统、真实减压模型（氮醉/减压停留只作为叙事字幕出现，不做数值系统）。

## 6. 垂直切片候选系统（P1 预研，详见 `WORKFLOW.md`）

- **气体细分**：底气/减压气双瓶规则简化版（三分之一法则的游戏化）；
- **线协议玩法**：手动布线/收线、线箭方向标记、断线接线小游戏；
- **能见度进阶**：全屏 silt-out 事件（只能摸线回家）；
- **"深处之物"行为化**：从纯氛围升级为"低频率、不可直视"的存在感设计；
- **分享卡图片化**：结算页生成可保存的下潜日志图片。

---

## 7. 目标玩家与平台

- **核心**：恐怖/氛围游戏爱好者、Subnautica"海洋恐惧"人群、洞潜与户外纪实内容消费者；
- **传播层**：短视频观众（"你敢一个人下去吗"式挑战内容），详见 `VIRAL_SOCIAL.md`；
- **平台**：桌面浏览器（Chrome/Edge/Firefox/Safari），零安装。

## 8. 参考作品

- 《Subnautica》——未知水域的敬畏恐惧、资源驱动的探索勇气；
- 《Iron Lung》——幽闭 + 信息不全恐怖的教科书；
- 《Outer Wilds》（Giant's Deep / Dark Bramble）——"知识就是进度"；
- 纪录片《Diving into the Unknown》《Dave Not Coming Back》——洞潜圈的真实规则与情感重量。
