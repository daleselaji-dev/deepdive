# DEEPDIVE · 研发工作流

> 本文档定义 DEEPDIVE（深潜）从原型到发布的研发流程。原则：**先设计后执行，小切片快迭代，每一轮迭代都必须让"第一眼"更震撼。**

## 1. 总体流程

```
设计文档 ──▶ 垂直切片原型 ──▶ 视觉/节奏迭代 loop ──▶ 内容扩展 ──▶ 打磨发布
   │              │                   │
   └── 评审 ◀─────┴───── 每轮迭代自测 ─┘
```

每个阶段的产出必须**可运行、可演示、可回滚**。禁止长期存在"半成品分支"。

## 2. 迭代 Loop（核心）

每一轮迭代固定走五步，单轮控制在一个可演示增量内：

1. **定目标**：本轮只解决一个问题（如"手电光锥的压迫感不够"），写进迭代记录。
2. **实现**：最小改动达成目标，避免顺手重构。
3. **自测**：`npm run dev` 桌面 + 手机模拟器各过一遍完整流程（标题 → 下潜 → 惊吓 → 结局）。
4. **首屏检验**：打开页面 3 秒内问自己——"陌生人会截图转发吗？"不会就没过。
5. **提交**：一个逻辑变更一个 commit，commit message 说明"改了什么、为什么"。

### 节奏专项自测清单（每轮必过）

- [ ] 前 60 秒是否只有压抑与暗示，没有廉价惊吓？
- [ ] 惊吓点前是否有"静默下沉"（声音先撤走）？
- [ ] 惊吓后是否留了余韵（不立即恢复正常）？
- [ ] 氧气焦虑是否在自然增长而非数值惩罚？

### 3.4 资产授权策略

- **只用两类外部资产**：CC0（公有领域）与 CC-BY（署名可商用）。禁止来源不明 / 授权不清的模型。
- **优先来源**：Khronos glTF-Sample-Assets（授权逐模型标注）、Kenney（CC0）、Quaternius（CC0）、Poly Haven（CC0）。
- **入库流程**：`scripts/fetch-assets.cjs` 下载（含镜像清单）→ gltf-transform 压缩（贴图 ≤256、meshopt）→ 压缩产物提交进 `src/assets/models/`（构建离线可复现）→ ASSETS_ATTRIBUTION.md 登记来源/作者/授权/改动。
- **体积红线**：模型二进制合计 ≤ 1.5MB（单文件 HTML 会 base64 内联，EXE zip 中出现两份拷贝，须守住 100MiB）。
- **下载失败预案**：换镜像重试并记录；仍失败则启用程序化中模 fallback（鱼体放样 + 鳍面片 + 眼球），观感显著高于三角锥。

### 3.5 洞潜安全模拟 · 尊重逝者红线

5 个模拟关是**模式化的事故类型重建**（能见度丧失 / 导览线方向错误 / 气体管理失败 / 失散 buddy / 减压停失败），参考公开洞潜安全教育文献中的**事故类型分类**，但人物、地点、经过**全部虚构**：

- 禁止使用真实遇难者姓名，禁止复刻任何一起具体公开事故的私人细节，禁止猎奇叙事。
- 模拟模式入口与每关简报均展示声明：「向洞潜安全教育致敬。本模拟全部虚构，不影射任何真实逝者与事故。」
- 复盘文案只讲**程序与教训**（该做什么），不渲染死亡过程。

### 3.9 生态科学诚实说明（分区依据）

本作地图设定为**尤卡坦半岛 anchialine（近海地下水系）天坑**：淡水透镜浮在入侵海水之上，两层之间是卤水跃层（halocline）。分区生态按此设计：

- **淡水层（Z1–Z4，卤跃层以上）**：真实天坑淡水段常见丽鱼科（如玛雅丽体鱼）、花鳉、墨西哥盲鱼类（如尤卡坦盲鳚）、洞穴盲螯虾（Creaseria morleyi 属型）、端足类/等足类。**不放真水母**——天坑淡水段通常罕见真海水母；淡水刺胞动物（水螅类）体型毫米级，不做大型奇观呈现。
- **卤水跃层以下（Z5–Z8）**：为海水来源水体，真实 anchialine 系统的标志物种是**桨足纲（remipede）**等海源穴居甲壳类；小型**水螅水母（hydromedusae）**在海水连通的洞穴系统有观察记录，故本作把水母**限制在 Z8 深渊（卤下）**并缩小为掌心尺度的半透明水螅水母群，不再是大型海月水母式生物。M3 版本水母曾以大型个体出现于深渊——M4-L4 已按本条修正尺度（0.16~0.30m 伞径）并把盲鱼/巡游大鱼迁回淡水层。**尺度诚实注**：真实桨足类体长 2~4cm，游戏内放大至约 30cm 以保证黑水环境的可读性（同类艺术放大也用于端足类微尘的发光表现）；H2S 界面附近枯木上的灰白色包壳与洞底菌毯，对应化能硫细菌席（如 Cenote Angelita 的实景记录）。
- **洞口段/气室（Z1 上部、支线C 蝙蝠气室）**：天坑洞口与气穴是蝙蝠栖息地，蝙蝠粪（guano）支撑洞穴无脊椎食物网——这是真实洞穴生态的能量输入之一；水上层有崖燕/翠鸰类活动。
- **奇虾（Anomalocaris）**：寒武纪早已灭绝，为本作的**幻想高潮元素**，游戏内文案亦以"不该存在于这个纪元"明示其超自然属性，不与上述真实生态混淆。

## 6. 决策记录

重大取舍记录在本节，避免反复：

- **2026-08：** 原型选 Three.js 第一人称 3D 而非 2D Canvas——洞潜的核心恐惧是"被体积包裹"，只有 3D 光锥+雾能传达。
- **2026-08：** 移动沿样条约束（隧道内自由游动但被管壁软约束）而非完全自由物理——保证叙事节奏可控，且规避复杂碰撞。
- **2026-08：** 音频全部 Web Audio 程序化合成——零资产、可参数化调节恐怖节奏。
- **2026-08（迭代 1 复盘）：** 无头浏览器截图回归发现两类渲染事故：① 自定义管几何的环向坐标与 three.js TubeGeometry 手性相反，配合 BackSide 剔除导致洞壁整体不可见——改用 DoubleSide 双面材质兜底；② 顶点 UV 已含平铺倍数时再叠加 `map.repeat` 会产生等高线状摩尔纹——平铺只允许在一处控制。已沉淀为截图回归流程（无头 Chrome + 调试钩子 `__dd.jump/o2` 跳点截图，双结局端到端验证）。
- **2026-08（M2 决策）：** 用户明确否决「红厅/竹节虫」结局——恐怖收束改为「远古生物目击 + 上潜生死闭环」。理由：竹节虫是借来的意象（极乐迪斯科），而"深渊里游着一条五亿年前的东西"是属于洞潜题材自己的敬畏；且上潜/减压/破水面给了玩法一个真实的"回程"，而不是撞线即结束。
- **2026-08（M2 决策）：** 地图采用**单条闭环 CatmullRom 样条**（去程左脉 + 回程烟囱共享天光井）而非多样条图结构——闭环让 `nearestT` 约束逻辑保持 O(窗口) 简单（只需环形回绕），回程天然是新风景，且支线用「短样条枝管 + 多路径最深包含判定」实现，避免通用图导航的复杂度。
- **2026-08（M2 决策）：** 焦散用 SpotLight.map 投射动画帧序列（Canvas 预生成 N 帧循环），体积光用加法混合锥体 + 菲涅尔渐隐着色器——都是"暗示体积"的廉价手法，不上 raymarch，为移动端保命。
