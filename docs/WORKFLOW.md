# DEEPDIVE · 研发工作流

> 本文档定义 DEEPDIVE（深潜）从原型到发布的研发流程。原则：**先设计后执行，小切片快迭代，每一轮迭代都必须让"第一眼"更震撼。**

## 1. 总体流程

```
设计文档 ──▶ 垂直切片原型 ──▶ 视觉/节奏迭代 loop ──▶ 内容扩展 ──▶ 打磨发布
   │              │                   │
   └── 评审 ◀─────┴───── 每轮迭代自测 ─┘
```

每个阶段的产出必须**可运行、可演示、可回滚**。禁止长期存在"半成品分支"。

## 2. 迭代 Loop（核心）

每一轮迭代固定走五步，单轮控制在一个可演示增量内：

1. **定目标**：本轮只解决一个问题（如"手电光锥的压迫感不够"），写进迭代记录。
2. **实现**：最小改动达成目标，避免顺手重构。
3. **自测**：`npm run dev` 桌面 + 手机模拟器各过一遍完整流程（标题 → 下潜 → 惊吓 → 结局）。
4. **首屏检验**：打开页面 3 秒内问自己——"陌生人会截图转发吗？"不会就没过。
5. **提交**：一个逻辑变更一个 commit，commit message 说明"改了什么、为什么"。

### 节奏专项自测清单（每轮必过）

- [ ] 前 60 秒是否只有压抑与暗示，没有廉价惊吓？
- [ ] 惊吓点前是否有"静默下沉"（声音先撤走）？
- [ ] 惊吓后是否留了余韵（不立即恢复正常）？
- [ ] 氧气焦虑是否在自然增长而非数值惩罚？

## 4. 技术工作流

- **分支**：`main` 保持可运行；功能走 `cursor/<desc>-a6e7` 类 feature 分支，PR 合入。
- **代码结构**：`src/game/` 下按系统分模块（Cave / Player / Story / Scare / Ending / Audio / HUD / Input），模块间通过 `Game` 状态机协调，禁止交叉引用 DOM。
- **资产策略**：原型期 **零外部资产**——几何程序化生成、纹理 Canvas 合成、音频 Web Audio 合成。好处：仓库轻、离线可跑、风格统一。M3 起引入压缩纹理（KTX2）与短音频（ogg），按 ART_DIRECTION.md 的品质层级管理。
- **性能预算**（原型期）：桌面 draw call < 60，移动端粒子减半、DPR ≤ 2、关闭阴影。详见 ART_DIRECTION.md §6。

## 5. 测试与验收

原型期以**流程自测**为主：

1. `npm run build` 必须零错误通过（TypeScript strict）。
2. 完整跑通三条结局路径（`node scripts/flow-test.cjs` 自动回归）：
   - E1 破晓：下潜→目击→回程→（减压）→破水面→登船；
   - E2 血里的针：高氮上浮且跳过减压停留后登船；
   - E3 浅睡：氧气耗尽→操控衰减→下沉收束。
3. 全区视觉回归：`node scripts/shots.cjs` 输出 17 张点位截图（9 区 + 浑水 + 目击三拍 + 水面 + 结局）。
4. 手机触控：虚拟摇杆 + 拖拽视角可完成全流程。
5. 刷新后从标题重新开始，状态无残留。

M3 起补充：叙事触发器的单元测试、氧气曲线的数值回归测试。

## 6. 决策记录

重大取舍记录在本节，避免反复：

- **2026-08：** 原型选 Three.js 第一人称 3D 而非 2D Canvas——洞潜的核心恐惧是"被体积包裹"，只有 3D 光锥+雾能传达。
- **2026-08：** 移动沿样条约束（隧道内自由游动但被管壁软约束）而非完全自由物理——保证叙事节奏可控，且规避复杂碰撞。
- **2026-08：** 音频全部 Web Audio 程序化合成——零资产、可参数化调节恐怖节奏。
- **2026-08（迭代 1 复盘）：** 无头浏览器截图回归发现两类渲染事故：① 自定义管几何的环向坐标与 three.js TubeGeometry 手性相反，配合 BackSide 剔除导致洞壁整体不可见——改用 DoubleSide 双面材质兜底；② 顶点 UV 已含平铺倍数时再叠加 `map.repeat` 会产生等高线状摩尔纹——平铺只允许在一处控制。已沉淀为截图回归流程（无头 Chrome + 调试钩子 `__dd.jump/o2` 跳点截图，双结局端到端验证）。
- **2026-08（M2 决策）：** 用户明确否决「红厅/竹节虫」结局——恐怖收束改为「远古生物目击 + 上潜生死闭环」。理由：竹节虫是借来的意象（极乐迪斯科），而"深渊里游着一条五亿年前的东西"是属于洞潜题材自己的敬畏；且上潜/减压/破水面给了玩法一个真实的"回程"，而不是撞线即结束。
- **2026-08（M2 决策）：** 地图采用**单条闭环 CatmullRom 样条**（去程左脉 + 回程烟囱共享天光井）而非多样条图结构——闭环让 `nearestT` 约束逻辑保持 O(窗口) 简单（只需环形回绕），回程天然是新风景，且支线用「短样条枝管 + 多路径最深包含判定」实现，避免通用图导航的复杂度。
- **2026-08（M2 决策）：** 焦散用 SpotLight.map 投射动画帧序列（Canvas 预生成 N 帧循环），体积光用加法混合锥体 + 菲涅尔渐隐着色器——都是"暗示体积"的廉价手法，不上 raymarch，为移动端保命。
