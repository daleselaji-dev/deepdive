# 工作流规划（Workflow & Milestones）

**项目：《回声园 / ECHO GARDEN》**
**路径：原型（P0） → 垂直切片（P1） → 垂直完整体验（P2）**

---

## 1. 阶段总览

| 阶段 | 目标问题 | 范围 | 验收标准（DoD） |
|---|---|---|---|
| **P0 原型（本仓库）** | 核心张力成立吗？值得继续吗？ | 纯 JS Canvas，一张程序化地图，一条完整"下潜-触碰-生还"循环 | 浏览器双击即玩；一局 5–8 分钟；扬尘/氧气/导览线三机制均可被玩家自然感知；日志可复制 |
| **P1 垂直切片** | 完整品质的 10 分钟长什么样？ | 一段手工精修洞穴 + 正式美术/音频替换 + 分享卡图片化 + 网页埋点 | 新玩家无引导完成率 ≥40%；切片视频可直接用作宣传素材；30 人外部测试 NPS 采样 |
| **P2 垂直完整体验** | 能撑起 2–3 小时的内容结构吗？ | 3 个生态带天窗群、线协议进阶玩法、深处之物行为化、叙事收束、双端（桌面 Web + 桌面打包） | 全流程通关率、留存、分享率达标；商店页/发行物料齐备 |

**阶段间设 Gate 评审**：不达 DoD 不进入下一阶段；每个 Gate 输出"继续 / 调整 / 终止"决议。

---

## 2. P0 → P1 迭代工作流（单次迭代节奏）

```
计划(Issue 列表) → 实现(feature 分支) → 自测(冒烟清单) → PR/合入
      ▲                                                    │
      └──── 复盘(数据+录屏) ◀── 灰度试玩(链接分发) ◀────────┘
```

- **分支规范**：`cursor/<feature>-<suffix>`（原型期）→ P1 起 `feat/ art/ fix/ docs/` 前缀；main 保持随时可玩。
- **提交纪律**：每个逻辑改动一个 commit；每次进入测试前必须 commit+push。
- **每迭代必做**：更新 `docs/` 中受影响的设计文档（文档即真相源）。

## 4. 资产管线（Asset Pipeline）

### 4.1 原则

- **P0：一切程序化**（已执行）——零外部文件，风格即代码；
- **P1 起：占位 → 正式两段式**——任何新资产先以程序化/灰盒占位进版本，玩法验证通过后才投入正式制作；
- **命名规范**：`<类别>_<对象>_<变体>_v<版本>`（如 `tile_rock_wet_v2.png`、`sfx_reel_click_v1.wav`）；
- **目录规范**（P1 起）：

```
assets/
  tiles/     岩壁与环境瓦片图集
  sprites/   潜水员与道具
  sfx/       采样音效（44.1kHz, ogg+fallback）
  ui/        仪表与字体
  ref/       参考图（不进构建）
```

### 4.2 提交门槛

- 图像资产：尺寸为 2 的幂或图集规范内；单文件 ≤ 512KB；
- 音频资产：响度统一 -16 LUFS；循环点无爆音；
- 每类资产首件必须过"游戏内截图评审"（在黑暗光照下检查，而非资源查看器里）。

## 5. 技术演进路线

| 阶段 | 技术栈 | 迁移触发条件 |
|---|---|---|
| P0 | 纯 HTML/CSS/JS + Canvas 2D，零依赖 | — |
| P1 | 仍为纯 Web；引入模块拆分 + 轻量打包（esbuild）与简单埋点 | 单文件复杂度失控时拆分 |

## 6. 测试与验证步骤

### 6.1 冒烟清单（每次合入前，5 分钟）

1. `python3 -m http.server` 打开 `prototype/index.html`，控制台无报错；
2. 标题页 6 行文案与开始按钮正常显示；点击后进入游戏且计时启动；
3. WASD/方向键移动、鼠标转灯、Shift 缓速均生效；
4. 贴墙冲刺能扬尘且光圈收缩；氧气随时间与运动下降；
5. 拾取气瓶 +40%；进入气室缓慢回氧；水面回氧；
6. 触碰深处之物触发事件与回程状态；返回水面出现生还结算；
7. 氧气归零出现黑视与死亡结算；两种结算的"复制日志"均可复制；
8. `?seed=test` 与当日默认种子分别生成稳定一致的地图；
9. R 重开、M 音频开关正常；刷新后 localStorage 下潜次数递增。

### 6.2 可玩性测试脚本（M1 起，每轮 5–8 人）

- 不给任何说明，只给链接；记录：首次死亡原因、是否理解导览线、是否发现气室、主动重开次数、是否点击复制日志；
- 测后三问："哪一刻最害怕？""哪一刻最想放弃？""你会把它发给谁？"

### 6.3 性能与兼容预算

- 目标 60fps @ 1080p（Canvas 2D，粒子上限 400 已封顶）；
- 兼容矩阵：Chrome / Edge / Firefox / Safari 最新两个大版本；
- 弱机降级：粒子减半开关（P1 实现）。

### 6.4 数据埋点（P1 实现，原型期用人工观察代替）

- `start_click`、`first_death{depth,cause}`、`artifact_touched`、`run_end{result,depth,time}`、`log_copied`。

## 7. 风险登记（Top 5）

| 风险 | 影响 | 缓解 |
|---|---|---|
| 真实事件借势引发舆情反感 | 品牌伤害 | 严格执行 `VIRAL_SOCIAL.md` 伦理红线；物料预审 |

| 单人开发范围蔓延 | 交付失控 | Gate 评审制度；MVP 不做清单写入设计文档 |
